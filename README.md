# CIDR Calculator

A fast, dependency-free IPv4 CIDR calculator that runs locally in the browser.

### Features
- Network and broadcast address
- Subnet and wildcard masks
- First/last usable address
- Total and usable host counts
- Responsive dark UI
- No backend, dependencies, or network requests

Open `index.html` directly in a browser.

> Host counts for /31 and /32 follow modern point-to-point/single-host conventions rather than subtracting two addresses.
